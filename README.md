# LomiriDock Monitor

A modern DevOps-oriented Lomiri application for monitoring and managing Docker containers using QML frontend and Python backend on Linux.

---

## Features

- Docker container monitoring
- Start and stop containers
- Docker logs viewer
- CPU and RAM monitoring
- Linux command execution
- DevOps-style dark dashboard UI

---

## Technologies Used

- Lomiri QML
- Python
- Docker
- Linux
- psutil
- subprocess

---
